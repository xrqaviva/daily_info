# A股盘前双源晨报

中国时间工作日 07:40 启动、只在上交所与深交所官方日历一致确认的 A 股交易日生成晨报。输出覆盖：

- 标普500、纳斯达克综合、道琼斯工业指数；
- 标普500 11 个 GICS 一级行业 ETF 的表现前三与表现后三；
- 富时100、CAC40、DAX，DXY 与美元兑人民币/欧元/日元/英镑的官方日度参考汇率；
- COMEX 黄金/白银/铜、WTI、现货黄金/白银、LME 六种基础金属、国内期货，以及钨钼小金属；
- 沪深北非 ST、非停牌股票的上涨/下跌/平盘家数；
- 最多 20 条重要宏观新闻。

盘前主表只接受采集时点前最近一个已完成交易日的日线收盘。盘中连续报价即使已经滚动到北京时间当日，也不能覆盖上一完整收盘；这类观察值会保留在证据文件中，但主表隐藏其数值并标记日期异常。

数值只有在同品种、同单位、同合约、同数据日期、同前值且不过期的独立来源落入容差时才显示共识。单源、缺失或冲突不会填 0，也不会选择性覆盖；报告会列原始值、绝对变化、变化比例、数据日期、来源 URL 和核验状态。钨的现货与协会预测价口径不同，保留各自合约与发布日期，不强行合并。A 股涨跌家数还要求双源股票代码集合完全相同、交易日正确且覆盖沪深北三市。

新闻候选来自盈米接口和国家统计局、美联储、欧洲央行等官方 RSS，数量或必需分类不足时可调用 Codex 联网搜索补充 URL。候选本身不算证据：程序会重新抓取每个 URL 核对网页标题和发布时间。官方一手域名允许单源，媒体事件必须由两个不同注册域名佐证。

新对话生成日报时，先读 [日常报告交接](docs/日常报告交接.md)；运行方法、输出位置、密钥和定时任务状态见 [运行与安装](docs/运行与安装.md)。LaunchAgent 已于 2026-07-20 安装并加载；系统唤醒设置未修改。

通用市场接口请求模板统一沉淀在 `/Users/aviva/Projects/stock/config/market_api_registry.json`。它是共享接口目录，不是运行时依赖，也不代表某次数据已经完成双源核验。

免费源若临时不可访问，程序只有限重试一次并降级为单源或不可用，不使用日期不明的新闻数字冒充行情。
