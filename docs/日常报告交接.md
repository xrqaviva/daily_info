# 日常报告交接

这份文件是切换到新对话后的唯一日常入口。新对话收到“生成今天的 A 股盘前报告”后，应先读项目根目录 `AGENTS.md` 和本文件，再直接运行现有流水线；不依赖旧对话记忆，也不手工抄写用户曾提供的示例数据。

## 一句话启动

在新对话中可以直接说：

> 读取 `/Users/aviva/Projects/daily_info/AGENTS.md` 和 `docs/日常报告交接.md`，使用现有接口完整生成今天的 A 股盘前报告，并检查报告日期、核验状态和 evidence；不要用盘中值覆盖上一完整收盘。

## 正式项目与共享接口目录

- 日常盘前报告项目：`/Users/aviva/Projects/daily_info`
- 通用市场接口目录：`/Users/aviva/Projects/stock/config/market_api_registry.json`
- 两个项目分别运行。`daily_info` 不导入 `stock` 的报告代码；只有需要了解、补充或替换接口时才读取共享注册表。
- 注册表记录请求模板、认证引用、日期语义、合约、限制、核验日期和现有消费者。登记在册不代表本次数据已完成双源核验，使用前仍需检查日期、单位、合约与响应结构。

## 正式运行

正常生成当前时点报告：

```bash
cd /Users/aviva/Projects/daily_info
python3 -m morning_brief.cli run --root /Users/aviva/Projects/daily_info
```

需要按指定历史截止时间重跑时，必须传带时区的 ISO 8601 时间；不带时区时程序会按中国时间解释：

```bash
python3 -m morning_brief.cli run \
  --root /Users/aviva/Projects/daily_info \
  --as-of 2026-08-13T07:40:00+08:00
```

`--as-of` 是回放截止时间，不是强行指定某个行情日期。程序仍会计算该时点之前最近一个已完成交易日，并通过上交所、深交所年度日历确认 A 股交易日。不要为了得到预期数字把时间改到未来。

## 运行结果判断

CLI 返回以下状态之一：

- `generated`：报告已生成并原子切换为 index。
- `skipped`：确认当天为 A 股非交易日；不生成，休市新闻留到下一份报告。
- `blocked`：交易日历无法确认；失败关闭，不采集并发布正式报告。
- `error`：运行异常。先检查日志和锁，不要用旧数据冒充今天报告。

生成后必须同时检查：

```bash
readlink reports/index
sed -n '1,260p' reports/index/A股盘前晨报.md
jq '{report_date,as_of}' reports/index/evidence.json
jq . reports/index/state.json
```

正式输出：

- `reports/index/A股盘前晨报.md`
- `reports/index/A股盘前晨报.html`
- `reports/index/evidence.json`
- `reports/index/state.json`

`reports/index` 是总索引，指向最近一次完整运行目录；`reports/YYYY-MM-DD` 是当天日期归档，只在当天**首次成功运行**时建立，同日重跑不会改动它（重跑只更新 `index`，不覆盖归档）。不要单独复制 Markdown 覆盖 index；报告、HTML、evidence 和 state 必须来自同一次原子发布。如需人工替换某天归档，可删除日期软链后重跑。

### HTML 生成与共享样式

每日流水线生成 Markdown（`A股盘前晨报.md`）；HTML 由 md 经固定模板自动转换得到（`morning_brief/templates.py` 的 `md_to_html`），不再从数据模型单独渲染。样式集中在共享文件 `reports/report.css`，所有页面引用同一个文件（带版本号 `?v=N`，改样式内容时必须同步递增 `templates.py` 的 `CSS_VERSION`，否则浏览器会命中旧缓存）；模板或样式变更后，运行 `python3 scripts/rerender_html.py` 把全部历史 run 的 HTML 从各自 md 重渲染（只改 HTML，不动 md/evidence/state），保证所有页面同模板。

## 每日报告固定口径

### 美股和欧洲市场

- 美股三大指数：标普 500、纳斯达克综合、道琼斯工业。
- 板块：标普 500 十一个 GICS 一级行业 ETF 的表现前三与表现后三。
- 欧洲：英国富时 100、法国 CAC 40、德国 DAX。
- 所有数据必须使用采集时点前最近一个已完成交易日，展示值、绝对变化和变化比例。
- 北京时间早晨美股尚未开盘时，使用上一完整美股交易日收盘；禁止把当天未开盘状态或其他日期数据写成当日收盘。

### 固定核心美股篮子现状

用户已经确认未来需要每日固定展示：

- Mag 7；
- 存储三雄：美光科技、SK 海力士、闪迪；
- 光模块/光通信核心公司；
- 有显著行情或重大事件时可追加其他股票。

但截至本交接文件更新时，该结构化个股表尚未接入生产报告。当前生产报告的美股个股部分尚只有三大指数和行业 ETF；新闻中偶然出现个股不等于固定篮子已经完成。不得伪造固定表。后续实施必须从 `docs/superpowers/specs/2026-07-29-core-us-equity-watchlist-design.md` 继续，按 RED → GREEN 接入。

### 报告页面排布现状

用户还要求报告页面做到“重点方向优先，并按重要性和信息密度排布”。截至本交接文件更新时，这一页面重排尚未实现：当前确定性渲染顺序为各市场表、A 股宽度、新闻，核验状态（全部品种状态与告警项）折叠置于页面末尾（2026-08-14 用户确认的确定性规则）。新对话不得把它描述成已交付；若要实现，应先明确重点方向的确定性来源和排序规则，再按设计审批与 RED → GREEN 修改 `morning_brief/report.py`。

### 汇率和商品

- 汇率固定展示美元兑人民币、欧元、日元、英镑，并明确是官方日度参考汇率还是市场报价。
- 商品包括 COMEX 黄金、白银、铜，WTI，现货黄金/白银，国内期货，以及国际基础金属。
- 国际金属至少覆盖铜、铝、锌、铅、镍、锡；钴若接口不可用必须显示不可用。
- 钨、钼及其他小金属按具体品位、交付地、计价单位和发布日期分别记录。不同合同不能强行交叉验证。
- 当前 LME 表是供应商三个月连续行情，不是 LME 官方 Closing Price；必须保留这一标签。
- 连续合约换月时不得用相邻连续收盘机械计算环比；优先使用同一合约的供应商结算变化，无法证明则标记冲突或不可用。

### A 股涨跌家数

- 统计上一 A 股交易日沪深北市场。
- 不包含 ST、退市整理和停牌股票；平盘单列。
- 新浪和东方财富必须证明相同交易日、完整分页、沪深北覆盖、无重复代码且有效股票集合一致，才可显示双源共识。
- 若股票集合仅差一只也要保留双方原值并标记冲突，不能擅自平均或选边。

### 新闻

- 重要新闻最多 20 条，涵盖宏观政策、隔夜美股与财报、产业、公司和国内商品期货。
- 国家统计局、美联储、欧洲央行、SEC 等官方一手原文允许权威单源。
- 普通媒体新闻必须由两个不同注册域名交叉证明；两个搜索工具不是两个独立新闻源。
- 必须复抓最终 URL，核对网页标题和发布时间。候选标题、搜索摘要或接口返回的数字不能直接当事实。
- 周末和 A 股节假日不生成，期间重要新闻并入下一份成功报告。

## 核验与失败关闭

只有同品种、同单位、同合约、同数据日期、同前值且差异在容差内的独立来源才能形成数值共识。以下情形必须明确展示，不能幻觉补齐：

- `verified`：已双源核验，可显示共识值。
- `single_source`：仅单源，列来源原值并标记待核验。
- `conflict`：双源日期、合同、前值或数值不一致，列双方证据；涉及错误日期时隐藏数值。
- `unavailable`：没有合格数据，显示不可用。

新闻可以按上述权威单源例外处理，但行情数字没有新闻兜底。网上搜索只用于发现候选 URL 或解释背景，不得替代结构化行情接口。

## 故障排查

1. 查看 `state/launchd.err.log` 和 `state/launchd.out.log`。
2. 检查是否已有运行锁：`state/run.lock`。程序会拒绝覆盖两小时内的有效锁；不要在未确认进程状态时手工删除。
3. 检查密钥来源：默认只读 `/Users/aviva/Projects/stock/.yingmi_api_key`，也可通过 `YINGMI_KEY_FILE` 指定。不得打印或提交密钥。
4. 检查 `config/runtime.json` 中 Codex 可执行文件路径；Node/Codex 升级后绝对路径可能失效。
5. 某个接口失败时先读取共享注册表的限制和最后核验日期，再决定是否需要在线复测。不得静默替换成不同合同。
6. 若 index 仍指向上一交易日，先看 CLI 状态是 skipped、blocked 还是 error；不要仅凭文件存在判断今天已生成。

## 自动任务

LaunchAgent `com.aviva.daily-info` 在周一至周五 07:40 尝试运行 `scripts/run_morning.sh`，脚本失败时最多重试三次。A 股节假日由交易日历门禁跳过。检查命令：

```bash
launchctl print gui/$(id -u)/com.aviva.daily-info
```

电脑睡眠会影响准点启动；系统唤醒设置不属于日常报告任务的默认授权范围。
