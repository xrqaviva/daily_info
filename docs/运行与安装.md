# 运行与安装

跨对话的完整口径、检查清单和未完成项见 [日常报告交接](日常报告交接.md)。本文件只保留安装与运行细节。

## 手工运行

```bash
cd /Users/aviva/Projects/daily_info
python3 -m morning_brief.cli run --root /Users/aviva/Projects/daily_info
```

程序先在线读取上交所和深交所年度休市公告。两份日历不一致或任一不可用时失败关闭；确认休市时正常退出且不生成文件；确认交易日后才采集行情、A 股宽度和新闻。

输出通常通过 `reports/YYYY-MM-DD/` 访问（当天日期归档，只在首次成功运行时建立，同日重跑不改动）；`reports/index.md`、`reports/index.html`、`reports/index.json` 指向最新成功运行。Markdown、HTML、evidence 和 `state.json` 会先写入同一 `reports/.runs/` 运行目录，最后只切换一次 `reports/index` 指针；任一提交前步骤失败时，上一份报告和上一份状态会保持配套。日期归档在当天首次成功提交时创建；若它单独失败，本次仍视为成功、返回 `index` 路径并附带警告，避免自动重试覆盖已经成功的新闻窗口。因此周末和节假日新闻会从上一份成功晨报的截止时间继续累计。

A 股涨跌家数只有在两个来源均携带正确交易日、覆盖沪深北、代码集合完全相同且没有重复代码时才标记已核验。两源即便数值一致，数据超过允许时效也不会形成共识。

## 密钥

默认只读使用 `/Users/aviva/Projects/stock/.yingmi_api_key`。也可设置：

```bash
export YINGMI_KEY_FILE=/absolute/path/to/yingmi-key
```

密钥不进入命令行参数、报告、日志或 evidence 文件。

Codex 新闻补源使用 `config/runtime.json` 中的绝对可执行文件路径，避免 LaunchAgent 的精简 `PATH` 找不到命令。Node/Codex 升级后若路径变化，需要同步更新该配置。

## 定时任务

`launchd/com.aviva.daily-info.plist` 已于 2026-07-20 复制到用户 LaunchAgents 并成功加载。系统当前登记周一至周五 07:40 启动；A 股节假日由程序门禁跳过。可用下列命令检查状态：

```bash
launchctl print gui/$(id -u)/com.aviva.daily-info
```

若电脑在 07:40 睡眠，LaunchAgent 不保证准点运行。2026-07-20 检查到现有工作日自动唤醒时间为 07:58，且系统唤醒设置尚未修改；要严格保证 07:40 启动，仍需另行授权把唤醒时间提前到 07:35。

## 年度维护

`config/calendar.json` 对官方年度休市公告采用明确 URL。进入新年度前必须加入上交所与深交所当年公告；未配置时程序会失败关闭，不会把普通工作日猜成交易日。
